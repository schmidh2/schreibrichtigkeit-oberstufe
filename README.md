# Schreibrichtigkeit Oberstufe

Nachschlagewerk mit Online-Übungen zur Sprachrichtigkeit für die Oberstufe und die Matura. Teil 1: **Komma** mit Entscheider, sieben Kommafällen (Regel, Probe, typische Fehler) und 64 Übungssätzen zum Kommasetzen.

Projektnotizen siehe [CLAUDE.md](CLAUDE.md). Lokal testen: `python3 -m http.server`, dann http://localhost:8000.
