# Schreibrichtigkeit Oberstufe

Nachschlagewerk mit Online-Übungen zur Sprachrichtigkeit für die Oberstufe und die Matura. Teil 1: **Komma** mit Entscheider, acht Kommafällen (Regel, Probe, typische Fehler) 75 Übungssätzen zum Kommasetzen sowie druckbaren Arbeits- und Lösungsblättern.

Projektnotizen siehe [CLAUDE.md](CLAUDE.md). Lokal testen: `python3 -m http.server`, dann http://localhost:8000.
